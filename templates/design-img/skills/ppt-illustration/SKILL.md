# PPT / 文档插图（ppt-illustration）

> PPT 配图、文档插图、汇报用示意图。特点是**辅助表达，不能抢戏**——插图是为内容服务的。

## 1. 尺寸选择

| 用途 | size |
|---|---|
| PPT 全幅背景/章节页 | `1424x800`（16:9，贴合幻灯片比例） |
| PPT 半版/左右版式配图 | `1152x864`（4:3） |
| 文档内嵌图 | `1152x864` 或 `1024x1024` |

## 2. 风格纪律（PPT 插图的核心）

- **默认扁平插画风**：线条简洁、色块干净、商务感，适配绝大多数汇报场合。用户没指定风格就按这个来。
- **配色跟着 PPT 主题走**：问一句 PPT 是什么色调（或用户说了深色/浅色主题），插图配色保持一致——深色主题的 PPT 配浅色底插图会很突兀。
- **元素克制**：一张插图只表达一个概念；人物/物体数量少、留白多。花哨的插图会抢走观众对文字的注意力。
- **不要文字**：PPT 插图里一律不画文字（标题由 PPT 自己排，图里写字既糊又重复）。

## 3. prompt 结构模板

```
扁平插画风格，商务简洁。主体：____（一个核心概念/场景）。
配色：____（与 PPT 主题一致，如"深蓝+白色+少量橙色点缀"）。
大量留白，无文字，无边框。
```

## 4. 常见场景

- 章节过渡页：抽象意象（登山=挑战、灯塔=方向、拼图=协作）+ 大面积留白放标题。
- 流程/关系示意：AI 画不好带箭头的精确流程图——这类需求建议用户用 PPT 自带 SmartArt；AI 适合画"氛围示意"而非"精确图示"，直说。
- 数据配图：数据图表本身用 Excel/PPT 图表做，AI 配图只做情绪/场景烘托。

## 5. 批量配图

- 整份 PPT 配多张图：先定一套风格关键词（写进每次 prompt），逐页分次生成，保证全套图风格统一。
- 风格统一性要求高时，把第一张满意的图作为参考图传入后续生成。
