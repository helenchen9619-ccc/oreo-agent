# 公众号 / 社媒配图（social-cover）

> 公众号头图、文章配图、社交媒体分享图。特点是**尺寸规矩多、一次要多个规格**。

## 1. 尺寸对照表

| 渠道 | 比例 | size |
|---|---|---|
| 公众号头图（大图） | ≈2.35:1 宽幅 | `1568x672`（21:9 最接近） |
| 公众号次条/小图 | 1:1 | `1024x1024` |
| 文章内插图 | 横版 | `1152x864`（4:3） |
| 小红书/竖屏社媒 | 3:4 / 9:16 | `864x1152` / `800x1424` |
| 视频号/B站封面 | 16:9 | `1424x800` |

注意：21:9 只是最接近公众号头图的平台档位，提示用户下载后按 900x383 裁切到精确尺寸。

## 2. 一稿多尺寸流程

1. 先按主渠道尺寸生成一张，用户确认满意；
2. 再分次生成其他尺寸变体：prompt 主体描述保持不变，只改构图描述（"横版改竖版构图，主体居中上移"）和 size；
3. 需要严格一致时，把第一张的 gen_imgs/ 路径作为参考图传入再变体。

## 3. 头图设计要点

- 头图在信息流里很小，**主体要大、对比要强、元素要少**——远景小人在信息流里等于没有。
- 标题文字：遵循 poster-design 的文字纪律（≤2 行、显式写出）；公众号标题本来就显示在图下方，头图也可以不带字——主动问用户要不要字。
- 系列文章配图：定一个风格基调（如"扁平插画+蓝白配色"），每篇沿用，形成栏目识别度。

## 4. 配图与文章的关系

- 用户给了文章：先读（工作区文件或粘贴），提炼核心情绪/意象再画，不画与内容无关的"好看图"。
- 拿不准用户要什么时，先给 2-3 个意象方向一句话描述（如"可以画 A 方向：…；B 方向：…"），用户选定再生成。
