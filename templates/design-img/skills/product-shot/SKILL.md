# 产品图 / 电商图（product-shot）

> 产品宣传图、电商主图、场景图。铁律：**产品的样子不能变**——AI 凭想象画的产品图一文不值，必须传参考图保一致性。

## 1. 铁律：产品一致性 = 必须传参考图

- 用户要画自家产品，第一件事：请用户上传产品照片（白底图最佳）。
- 调用 image_generate 时把产品图路径传入 `images`；prompt 里写"保持参考图中产品的外观、颜色、造型完全不变"。
- 用户没有产品图：直说"凭空画的产品和你家实物对不上，不建议这么做"，引导上传；用户坚持就画"概念示意图"并明确标注。

## 2. 常见类型与 prompt 要点

| 类型 | 要点 | size |
|---|---|---|
| 白底主图 | 纯白背景、产品居中、柔和无影 | `1024x1024` |
| 场景图 | 产品融入使用场景（厨房/办公桌/户外），自然光影 | `1152x864` 或 `1024x1024` |
| 促销海报图 | 产品+促销氛围元素，文字纪律同 poster-design | `864x1152` |
| 细节特写 | 材质质感（金属/玻璃/布料）、微距光效 | `1024x1024` |

## 3. 多角度 / 多场景变体

- 同一产品要多个角度或场景：分次生成，每次都传同一张产品参考图，只改场景描述。
- 风格迁移：用户给一张"别人家的效果图"说"照这个感觉做"→ 产品图+风格参考图一起传 images（最多 10 张），prompt 写清"产品外观以图1为准，画面风格参考图2"。

## 4. 文案叠加

- 卖点文字参照 poster-design 的文字纪律：≤2 行、显式写出文字内容。
- 电商主图常见的"到手价 ¥XX"角标：不要画进图里（数字容易错），提醒用户后期在电商后台或设计软件里加。
