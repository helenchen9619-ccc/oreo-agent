# 海报 / 宣传物料（poster-design）

> 活动海报、节日海报、内部宣传物料。核心矛盾：**AI 生图的文字渲染有上限，海报又必须有字**——纪律就是围绕这个矛盾定的。

## 1. 尺寸选择

| 渠道 | size |
|---|---|
| 手机竖版海报（朋友圈/群内转发） | `864x1152`（3:4）或 `800x1424`（9:16） |
| 横版海报（大屏/投影/横幅） | `1424x800`（16:9）或 `1568x672`（21:9） |
| 方形（社群头像式物料） | `1024x1024` |

## 2. 文字渲染纪律（最重要）

- **主标题 ≤10 个字**，字号在画面中要"大"（prompt 里写"超大号标题文字"）。
- 全图文字总量 ≤2 行：主标题 + 一句副标题（≤15 字）。时间/地点/二维码/详细说明**不要画进图里**，留白让用户后期加。
- prompt 中文字必须显式写出，如 `海报顶部超大号中文标题"中秋团圆惠"`——不写清楚模型会自己编字。
- 用户给了大段文案：主动帮他精简成主标题+副标题两句，商量确认后再画。

## 3. 品牌元素

- 公司 Logo / 吉祥物 / VI 色：**用户必须上传参考图**（image_generate 传 images），没提供就预留位置（prompt 写"顶部留白区域"）并提醒后期贴。
- 品牌色写进色彩基调：如"主色调深蓝+金色点缀"。

## 4. prompt 结构模板

```
[用途]海报，竖版构图。主体：____（场景/人物/产品，含动作与情绪）。
风格：____（扁平插画/国潮/3D 渲染/写实摄影…）。光影：____。色彩基调：____。
顶部超大号中文标题"____"，下方副标题"____"。底部留白。
```

## 5. 常见翻车与对策

- 字糊/错字 → 字数超了，精简后重画
- 风格不对 → 下次生成时在 prompt 里加参照风格关键词（如"参考苹果发布会海报的极简风"）
- 要 3 个方案 → 分 3 次生成，每次换不同风格方向（插画风/摄影风/3D 风），让用户挑
