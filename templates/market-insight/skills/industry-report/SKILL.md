# 行业研究报告（industry-report）

> 行业全景类需求的结构模板与搜索策略。先读 deep-research 底座流程，本文件定义报告骨架。

## 报告骨架（按此组织，缺哪节标"未覆盖"）

1. **市场规模与增速**：当前规模、近 3 年 CAGR、未来 3 年预测。
   注意：不同机构口径差异极大（出厂口径/零售口径/含不含细分），并列来源并注明口径。
2. **产业链结构**：上游（原料/供应商）→ 中游（生产/品牌）→ 下游（渠道/终端），
   各环节利润池与议价力。
3. **竞争格局**：头部玩家名单、份额、梯队划分；近一年新进入者与退出者。
4. **驱动因素**：需求侧（消费习惯/场景变迁）、供给侧（技术/成本）、政策侧。
5. **风险与挑战**：监管/食安、同质化、成本波动、替代品。
6. **结论与启示**：对本公司的三条 actionable 建议（结合用户说明的业务背景）。

## 搜索策略（按节给关键词模式）

- 规模增速：`{行业} 市场规模 {年份}` / `{行业} 白皮书 / 研究报告` / `{行业} CAGR`
- 竞争格局：`{行业} 头部品牌 份额` / `{行业} 融资 {年份}` / `{行业} 开店 关店`
- 驱动与风险：`{行业} 趋势 {年份}` / `{行业} 监管 政策` / `{行业} 消费洞察`
- 优先来源：研究机构（艾瑞/弗若斯特沙利文/欧睿转载）、行业垂直媒体、上市公司财报与招股书
  （最有含金量的公开来源，记得搜 `{头部公司} 财报 / 招股书`）。

## 纪律

- 市场规模类数字**必须双来源**，单来源标注待验证；机构数字照引，不自行加权平均。
- 财报/招股书数据优先于媒体报道（媒体经常转错）。
- 报告开头注明"信息截至 {日期}"，结尾列来源附录（格式同 deep-research）。
- 骨架是默认结构：用户给了自己的模板/栏目要求，按用户的来。
