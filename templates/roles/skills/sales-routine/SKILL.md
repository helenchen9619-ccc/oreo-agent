# 销售日常文书（sales-routine）

> 客户跟进纪要、销售周报、方案报价文档。核心：**让销售少写字，让每份文档都推动成交**。

## 1. 跟进纪要 → 结构化

用户丢来散乱的记录（聊天记录、语音转写、零碎笔记），整理成固定结构：

| 字段 | 说明 |
|---|---|
| 客户/联系人 | 公司名 + 对接人 + 角色（决策人/影响者/使用者） |
| 需求与痛点 | 客户原话优先，不臆造 |
| 我方方案/报价 | 已给客户的承诺如实记录 |
| 异议与顾虑 | 价格/功能/时机，客户的真实阻碍 |
| **下一步** | 动作 + 负责人 + 时间点（没有就先和用户确认，这是纪要的灵魂） |

- 素材里没有的字段标"待补充"，不编造客户没说过的话。
- 多个客户的混杂记录，先按客户拆分再逐个整理。

## 2. 销售周报骨架

1. **本周成果**：签单/回款/新增意向客户（数字开头）
2. **重点客户进展**：每个客户一行——阶段变化 + 关键动作 + 下一步
3. **漏斗概况**：各阶段客户数与金额，环比变化
4. **问题与所需支持**：需要老板/其他部门协调的事（销售周报的独特价值）
5. **下周计划**：3-5 条，每条带目标产出

## 3. 方案 / 报价文档结构

1. 客户需求理解（用客户的语言复述，证明听懂了）
2. 方案概述 → 详细内容（分点，突出与客户痛点的对应）
3. 报价明细：**表格呈现**，条目、单价、数量、小计、总计、含税说明——逐项与用户核对后再生成
4. 商务条款：交付周期、付款方式、质保/售后
5. 为什么选择我们（2-3 条差异化卖点，不吹牛）

## 4. 纪律

- 价格/折扣/账期等数字**必须用户确认后再写入正式文档**，生成后提醒用户复核关键数字。
- 客户名单、报价、合同条款是机密：不联网外发、不写入共享区。
- 文档用 doc-report 技能产 .docx；客户/回款数据分析表产 .xlsx（excel-ops 纪律）。
