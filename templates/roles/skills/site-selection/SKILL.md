# 选址评估与商务谈判（site-selection）

> 点位评估、点位对比、商务条件谈判。核心：**同一套尺子量所有点位，把谈判条件清单化**。

## 1. 选址评分卡

评估任何点位前先建评分卡（Excel），维度：

| 维度 | 考察点 | 典型数据来源 |
|---|---|---|
| 商圈能级 | 商圈等级、辐射人口、消费力 | 公开数据 + web_search |
| 客流 | 日均客流、高峰时段、目标客群占比 | 实地蹲点/商场方数据 |
| 可见性与可达性 | 门头展示面、楼层/位置、动线、停车 | 踏勘记录 |
| 竞争密度 | 同业态竞品数量与距离、差异化空间 | 实地 + web_search |
| 物业条件 | 面积、层高、水电燃气、排烟、承重 | 物业资料 |
| 商务条件 | 租金/扣点、免租期、押金、递增率 | 商场招商报价 |

- 各维度 1-5 分 × 权重 = 加权总分。**权重先和用户确认**（不同业态差异大：餐饮看排烟与客流时段，零售看展示面）。
- 定性信息（"这个位置感觉不错"）转成具体维度的描述，不单独作为评分依据。

## 2. 点位对比表

- 多点位比较：行=维度，列=点位，最后一行加权总分；优劣用颜色/标注区分。
- 对比结论不只给分数排名，还要给**风险点**：每个点位最大的硬伤是什么（如"客流大但租金超预算 40%""条件好但竞品 50 米内 3 家"）。
- 产 .xlsx 交付（excel-ops 纪律：公式可重算，打分改动自动重算总分）。

## 3. 商务条件谈判要点清单

每个进入谈判阶段的点位，产出一页纸清单（Word）：

1. **我方目标条件**：租金/扣点上限、免租期目标、递增率上限
2. **可交换筹码**：租期长短、装修标准、开业时间、品牌背书
3. **必争条款**：排他条款（同业态限制）、免租期、装修补贴
4. **可让步条款**：按优先级排序，让步前想清楚换什么
5. **退出保护**：违约金上限、不可抗力与解约条件、押金退还
6. **红线**：超过即放弃的条件（先和用户确认底线，清单里写明"底线不示人"）

## 4. 拓展进度周报

- 按 pipeline 阶段组织：线索 → 踏勘 → 评估 → 谈判 → 签约，每个点位一行：当前阶段、本周动作、卡点、下一步。
- 重点写**卡点与所需支持**（如"某点位需法务审合同条款"），这是周报对管理的价值。

## 5. 纪律

- 公司的目标区域、意向点位、出价底线是核心机密：不联网外发；web_search 只用于查公开的商圈/竞品/规划信息。
- 租金等关键数字注明来源（招商口头报价/书面报价/市场参考价），口头与书面要区分置信度。
- 评分卡产 .xlsx，谈判清单/周报产 .docx（doc-report 技能）。
