# 经营简报与决策支持（exec-briefing）

> 给老板/管理层的经营简报、专题分析。核心：**一页纸讲清"发生了什么、为什么、怎么办"**。

## 1. 一页纸经营简报骨架

1. **核心指标速览**：3-6 个关键指标（营收/利润/门店数/客流等，按公司业务定），每个带环比/同比/目标达成——表格呈现，异动标色
2. **本期异动与归因**：1-3 个最重要的变化，每个说清"事实 → 原因 → 是否可持续"
3. **风险提示**：正在逼近的问题（现金流/大客户流失/政策变化），按紧迫度排序
4. **决策建议**：需要管理层拍板的事，给 2-3 个选项 + 各自利弊 + 我的倾向（标注置信度）

原则：第一页看完就知道公司好不好、要干什么；支撑数据放附录。

## 2. 多源信息汇总（飞书动态）

「今天/本周公司有什么重要的事」类需求：

1. `feishu_chat_daily`（群聊+私聊动态）+ `feishu_approval_daily`（审批三段）+ `feishu_mail_daily`（邮件）一起调，统一提炼
2. 按重要度组织：需要决策的 > 需要知悉的 > 常规流转的
3. 审批卡点单独列：哪些流程卡住、卡在哪一环、卡了多久
4. 隐私红线：同事发言内容只回复给用户本人，不外发、不存长期记忆

## 3. 战略专题分析

- 行业趋势/市场规模 → `read_skill` 读 industry-report，按骨架展开
- 竞品动向 → 读 competitor-analysis
- 信息量大、需要多路搜索的 → 读 deep-research 按流程执行
- 内部数据 + 外部情报**交叉印证**：外部说"行业增长 20%"而内部营收下滑，指出背离并给可能解释，不和稀泥

## 4. 纪律

- 数据不足时标注假设与置信度（"基于 3 家竞品公开信息，样本有限"）；编造的精确数字是管理层决策的最大陷阱。
- 指标口径先确认：营收是含税还是不含税？门店数含不含加盟店？问不清就写明所用口径。
- 简报产 .docx（doc-report 技能），指标明细附 .xlsx；汇报场景需要 PPT 时用 ppt-make 技能。
- 涉及经营机密的文件不联网外发、不写入共享区。
