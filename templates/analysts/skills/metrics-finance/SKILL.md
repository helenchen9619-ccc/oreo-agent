# 财务指标口径与分析模板（metrics-finance）

> ⚠️ **口径为通用会计准则下的定义草稿，待财务部门确认后修订。** 本文件是财务指标的唯一口径来源：
> 计算任何财务指标时以本文件定义为准，不要凭记忆发明口径。公司核算制度与本文件不一致时，
> 指出差异并按公司口径执行（同时建议财务同事修订本文件）。

## 0. 动手前的四个确认（财务数据特有）

1. **含税/不含税**：收入和成本是含增值税还是不含税口径？混用会让毛利率等指标系统性失真。
2. **权责/收付**：利润表口径（权责发生制）还是现金口径？两者差异大时必须说明。
3. **单体/合并**：是单家公司报表还是集团合并报表？合并口径要抵销内部交易。
4. **期间对齐**：同比 = 与上年同期比；环比 = 与上一期间比。月度数据做同比要注意春节等季节性错月。

财务 Excel 常见坑：合并单元格、多级表头、借贷方向用正负数混排、合计行夹杂在明细里。
读取时先用 pandas 看 `head(20)` 摸清结构再解析，合计行要剔出来单独核对（明细加总 ≈ 合计行是数据质检的一部分）。

## 1. 偿债能力

**资产负债率** = 负债总额 ÷ 资产总额。
- 要点：没有"越低越好"——过低可能说明杠杆利用不足；结合行业水平看（地产 70%+ 常见，软件 30% 常见）。
- 必须同时给出分子分母绝对值，防止小分母造出夸张比率。

**流动比率** = 流动资产 ÷ 流动负债；**速动比率** = (流动资产 − 存货) ÷ 流动负债。
- 参考阈值（经验值，需按行业调整）：流动比率 2、速动比率 1。
- 要点：流动资产里如果应收/存货占比高，速动比率比流动比率更能反映真实短期偿债能力。

## 2. 营运能力（周转类）

**应收账款周转天数（DSO）** = 期间天数 × 平均应收账款 ÷ 期间营业收入。
**应付账款周转天数（DPO）** = 期间天数 × 平均应付账款 ÷ 期间营业成本。
**存货周转天数（DIO）** = 期间天数 × 平均存货 ÷ 期间营业成本。
**现金循环周期（CCC）** = DSO + DIO − DPO。

```python
# 平均余额 = (期初 + 期末) / 2；月度快照更准则用期间各期均值
avg_ar = (df["期初应收"] + df["期末应收"]) / 2
dso = period_days * avg_ar / df["营业收入"]
```

**账龄分析**（应收/应付都适用）：
- 标准分档：30 天以内 / 31-60 / 61-90 / 91-180 / 181-365 / 1 年以上。
- 输出：各账龄段金额 + 占比 + 环比变化；逾期（超过信用期）部分单独列出客户/供应商清单，按金额降序。
- 要点：1 年以上应收要提示坏账计提风险；账龄突然后移往往是客户资金链紧张的早期信号。

```python
bins = [0, 30, 60, 90, 180, 365, float("inf")]
labels = ["30天以内", "31-60天", "61-90天", "91-180天", "181-365天", "1年以上"]
df["账龄段"] = pd.cut(df["账龄天数"], bins=bins, labels=labels, right=True)
aging = df.groupby("账龄段", observed=True)["金额"].agg(["sum", "count"])
aging["占比"] = aging["sum"] / aging["sum"].sum()
```

## 3. 盈利能力

**毛利率** = (营业收入 − 营业成本) ÷ 营业收入。
**净利率** = 净利润 ÷ 营业收入。
**ROE（净资产收益率）** = 净利润 ÷ 平均净资产。

**杜邦拆解**（ROE 异动归因的标准动作）：
ROE = 净利率 × 总资产周转率 × 权益乘数
　　= (净利润÷营业收入) × (营业收入÷平均总资产) × (平均总资产÷平均净资产)
- ROE 变化时拆成三因子分别算贡献：是赚得更多了（净利率）、周转更快了（营运效率）、还是杠杆更高了（权益乘数）——三者含义完全不同，杠杆驱动的 ROE 提升要提示风险。
- 要点：分析盈利指标必须分业务线/产品/客户群拆开看，大盘毛利率不变可能掩盖结构恶化（高毛利业务占比下降）。

## 4. 现金流分析

**利润含金量** = 经营活动现金流净额 ÷ 净利润。
- 持续 < 1 说明利润没有变成钱（应收积压或存货占用），要下钻营运资本变动。
- 单期 < 0 是强警报，需立即提示。

**要点**：
- 三大活动分开看：经营（主业造血）、投资（扩张/收缩）、筹资（借钱/还钱/分红）。健康的成熟企业通常是 经营+ / 投资− / 筹资−。
- 净利润与经营现金流的差异调节（折旧摊销、营运资本变动）是解释"赚钱但没钱"的标准框架。

## 5. 预算执行（预实对比）

**达成率** = 实际 ÷ 预算（费用类指标注意方向：超预算 = 达成率 > 100% 是坏事，表达时用"超支 x%"避免歧义）。
**偏差额** = 实际 − 预算；**偏差率** = 偏差额 ÷ 预算。

偏差归因三维度（尽量拆到能行动的一层）：
- **部门/责任单元**：哪个部门超的；
- **科目/费用类别**：钱花在哪类上；
- **时间**：哪个月开始偏离，是单月异常还是趋势性偏离。

```python
df["偏差额"] = df["实际"] - df["预算"]
df["偏差率"] = df["偏差额"] / df["预算"]
# 按偏差绝对值排序，聚焦重大偏差；±5% 以内通常视为正常波动（阈值按公司制度调整）
major = df[df["偏差率"].abs() > 0.05].sort_values("偏差额", key=abs, ascending=False)
```

要点：累计口径和当月口径都要给——单月超支但累计在预算内，和累计已超，是完全不同的结论。

## 6. 费用分析

**费用率** = 期间费用 ÷ 营业收入（销售/管理/研发/财务费用分别算）。
- 看趋势（同比/环比）+ 看结构（各费用类别占比变化）+ 看弹性（收入涨 10% 费用涨多少，费用增速持续快于收入增速要提示）。
- 要点：费用异常波动先排除一次性因素（年终奖计提、审计费、大额摊销）再下结论。

## 7. 供应链财务（采购与库存的资金视角）

财务看供应链和供应链团队看自己角度不同：供应链看数量和时效，财务看**钱**——采购花了多少、库存压了多少、账期占了谁的资金。

**采购价格差异（PPV / 价差量差）**：
- 价差 = (实际采购单价 − 标准/预算单价) × 实际采购量；量差 = (实际采购量 − 标准用量) × 标准单价。
- 用途：采购成本超预算时，分清是"买贵了"（价差，找采购/行情）还是"用多了"（量差，找生产/损耗）。

```python
df["价差"] = (df["实际单价"] - df["标准单价"]) * df["实际数量"]
df["量差"] = (df["实际数量"] - df["标准数量"]) * df["标准单价"]
ppv = df.groupby("物料")[["价差", "量差"]].sum().sort_values("价差", key=abs, ascending=False)
```

**原物料成本率**（餐饮/食品/制造业主线指标）= 期间原物料成本 ÷ 期间营业收入。
- 按品类/门店/月份拆开看；成本率上升先分解：是采购价涨了（价差）、损耗/浪费大了（量差）、还是售卖结构变了（低毛利产品占比上升）。
- 与 BOM/标准成本联动：理论成本（BOM 标准用量 × 标准单价）vs 实际成本的差异率，是发现跑冒滴漏的核心抓手。

**库存资金占用**：
- 库存金额 = 库存数量 × 单位成本（确认计价方法：移动加权/先进先出/标准成本）。
- 库存资金占用成本 ≈ 平均库存金额 × 资金成本率（年化，公司 WACC 或贷款利率，未知则标注假设值）。
- **呆滞库存的财务影响**：呆滞超过一定期限（常用 180 天）要提示计提存货跌价准备的风险，金额 = min（账面成本 − 可变现净值， 账面成本），具体按公司计提政策。

**供应商账期与资金占用**：
- DPO 拉长 = 占用供应商资金，改善自身现金流，但过度拉长损害供应商关系、可能换来涨价；
- 分析维度：按供应商看账期结构（款到发货 / 月结 30 / 月结 60），测算"若统一收紧到 X 天"对现金流的冲击。

**物流仓储成本**：运输费、仓储费、装卸费归集后算**物流成本率** = 物流总成本 ÷ 营业收入（或 ÷ 发货量算单件物流成本），按线路/仓/月份拆，异常尖峰结合发货量看是费率问题还是货量问题。

**与供应链分析师的协作边界**：库存周转率、缺货率、OTIF 等运营口径指标归 metrics-supply-chain；
本节只负责把它们换算成资金占用、成本差异、跌价风险等**财务语言**。两边口径冲突时先对齐再算。
