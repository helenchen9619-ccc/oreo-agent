# Excel 操作纪律（excel-ops）

用 pandas + openpyxl 处理 Excel 时必须遵守的纪律。目标：**交付的表格专业、可重算、零错误**。

## 铁律

1. **写公式，不写死值**。交付的 Excel 里，凡是由同行/同表其他单元格算出来的值（合计、占比、周转率、均价），
   一律写 Excel 公式（如 `=B2/C2`、`=SUM(D2:D50)`），让下游打开文件改数后能自动重算。
   只有原始数据和文本标签写值。财务/经营模型尤其严格。
2. **改表先在副本上试跑**。修改用户已有的 Excel 时：
   复制 → 在副本上执行修改 → 校验 → 校验通过才把副本作为交付文件另存。绝不原地改用户的原始文件。
3. **交付前重算校验**。用 `scripts/recalc_check.py` 对产出文件重算并扫描错误
   （`#REF!`/`#DIV/0!`/`#VALUE!`/`#NAME?`/`#N/A`），目标零公式错误。有错误必须修复后再交付。
   用法：`python scripts/recalc_check.py <文件路径>`（先 read_skill 本技能获取脚本全文，或按附件路径执行）。
4. **编辑已有表格保留原样式**。不动字体/颜色/列宽/冻结窗格/已有格式；新增行列的样式与相邻行列对齐。

## 常见坑（每个都真实踩过）

- **读值**：`openpyxl.load_workbook(path)` 默认读到的是**公式字符串**不是值。要读计算结果用
  `load_workbook(path, data_only=True)`——但注意：如果文件没被 Excel 打开保存过，缓存值是 None。
  此时用 pandas 读（`pd.read_excel` 走缓存值，同样受限）或先用 formulas 重算。
- **`ws.cell(...).value = ...` 会覆盖格式**？不会，但 `text_frame` 式的整段重写思维在 Excel 里的对应物是：
  给已带样式的单元格赋值不会清样式，**新建单元格才是裸样式**——新区域的样式要显式 copy 自相邻单元格
  （`from copy import copy; new_cell.font = copy(ref_cell.font)`，font/fill/border/alignment/number_format 逐个复制）。
- **没有"复制整行/整列/整表"的 API**：openpyxl 不支持整行带样式复制，要逐单元格复制值+样式。
- **合并单元格**：写入只能写左上角锚点单元格，写其他位置会丢；读取同理。拆分用 `ws.unmerge_cells`。
- **大表**：行数上万时 openpyxl 逐格操作很慢，数值计算用 pandas 做，openpyxl 只负责写公式和样式。

## 常用正确写法

透视表、合并单元格、冻结窗格、条件格式、图表等标准写法，查阅附件
`references/openpyxl-recipes.md`（用 read_skill 带 path 参数读取）。**不要凭记忆写 openpyxl 代码**——
它的 API 细节极易写错（如已废弃的 `cell_range()`），先查片段库。

## 交付规范

- 文件名：默认在原文件名基础上加后缀说明（如 `_含公式.xlsx`、`_分析.xlsx`），不动用户的原始文件。
- **例外——用户明确说"做进/填进/更新这张表"时**（如"把核对结果做进到账资金比较表"）：
  这是「填充既有模板」任务，正确做法是：
  1. 把目标表作为 `files` 带进沙箱；
  2. 在沙箱里用 openpyxl 打开**这个文件本身**，在其空白区域/指定 sheet 填充数据（保留原格式）；
  3. 按**原相对路径**写到 `./output/`（如 `./output/财务数据核对/到账资金比较表.xlsx`）——
     平台会识别同路径并**覆盖更新原文件**，用户在工作区原位置就能看到结果。
- 用户指定"文件名+日期、存到同一文件夹"时：写到 `./output/<同一文件夹>/<文件名_YYYYMMDD>.xlsx`，
  产物会落在该文件夹下（不要在代码里自己造 sandbox_outputs 之类的目录）。
- 交付时在回答里说明：产物路径（用户要去哪里找）、哪些是原始数据、哪些是公式列、校验结果（重算零错误）。

## 任务确认纪律（防止做串任务）

每条新用户消息动手前，先用一句话向用户复述**当前任务目标**（"我现在的任务是：把 A 和 B 的核对结果填进 C 表"），
再执行。**不要重复执行已经完成的任务**：如果新消息和上一个任务不同，它就是新任务，旧任务的结果不要重算重报；
如果不确定新消息是新任务还是对旧任务的修正，先问一句再动手。
