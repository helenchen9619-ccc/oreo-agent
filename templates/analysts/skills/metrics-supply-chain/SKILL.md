## 1. 库存周转率 / 周转天数

**定义**：一定期间内库存被消耗并补充的次数。
**口径**：周转率 = 期间销售成本（COGS）÷ 期间平均库存成本；周转天数 = 期间天数 ÷ 周转率。
**要点**：
- 平均库存 = (期初库存 + 期末库存) ÷ 2（有月度快照则用期间各期均值，更准）。
- 分子用**成本**不用销售额（口径混用会系统性高估）；若只有销售额，说明并按销售额口径标注。
- 无成本数据时的近似：周转率 ≈ 期间销量 ÷ 平均库存数量（数量口径，需说明）。

```python
# 数量口径近似：按 SKU/仓库分组
avg_stock = (df.groupby(["仓库", "SKU"])["期初库存"].first()
             + df.groupby(["仓库", "SKU"])["期末库存"].first()) / 2
sales = df.groupby(["仓库", "SKU"])["期间销量"].sum()
turnover = (sales / avg_stock).rename("周转率").reset_index()
turnover["周转天数"] = period_days / turnover["周转率"]
```

## 2. 缺货率

**定义**：有需求但无法满足的比例。
**口径**（两种，必须说明用哪种）：
- SKU 天数口径：缺货率 = 缺货 SKU·天数 ÷ (在架 SKU 总数 × 期间天数) —— 反映货架可得性；
- 订单行口径：缺货率 = 未满足订单行数 ÷ 总订单行数 —— 反映客户体验。
**要点**：区分单点缺货（当天补货）与持续缺货（>3 天）；持续缺货要单独列出 SKU 清单。

## 3. 准时交付率（OTIF）

**定义**：准时且足量交付的订单占比（On Time In Full）。
**口径**：OTIF = 同时满足「交付日期 ≤ 承诺日期」且「交付数量 = 订单数量」的订单数 ÷ 总订单数。
**要点**：可拆成「准时率」和「足量率」两个子指标分别看瓶颈；部分交付的订单不计入 OTIF。

```python
df["准时"] = df["交付日期"] <= df["承诺日期"]
df["足量"] = df["交付数量"] >= df["订单数量"]
otif = (df["准时"] & df["足量"]).mean()
```

## 4. 滞销 SKU 识别

**定义**：有库存但长期无动销的 SKU。
**口径（草稿）**：期末库存 > 0 且近 N 天销量 = 0（N 默认 90，按品类调整：快消 30-60，耐用品 90-180）。
**输出**：滞销 SKU 清单 + 占用库存金额 + 占库存总额比例，按占用金额降序。

last_sale = df[df["销量"] > 0].groupby("SKU")["日期"].max()

## 5. 安全库存

**定义**：应对需求/供应波动的缓冲库存。
**口径（草稿）**：安全库存 = z × σ_d × √(提前期)，其中 σ_d 为日销量标准差，提前期单位为天，
z 由服务水平决定（95% → 1.65，97.5% → 1.96，99% → 2.33）。
**要点**：需求波动大或提前期不稳定的 SKU，σ 要用滚动窗口重算；安全库存是建议值，落地要结合最小起订量。

## 通用提醒

- 库存指标先确认：库存是期末快照还是期间均值？含不含在途？含不含残次品？
- 所有比率指标同时给出分子分母的绝对值，防止小分母造出夸张比率。
