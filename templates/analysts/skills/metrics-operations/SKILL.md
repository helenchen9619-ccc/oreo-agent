> 计算任何运营指标时以本文件定义为准。用户口径与本文件不一致时，指出差异并按用户口径执行。

## 1. RFM 用户分层

**定义**：按最近一次消费（R）、消费频率（F）、消费金额（M）三个维度给用户打分分层。
**口径（草稿）**：
- R = 统计截止日 − 用户最近下单日（天数，越小越好）；
- F = 统计窗口内下单次数（默认近 12 个月）；
- M = 统计窗口内累计实付金额（不含退款）。
- 打分：各维度按五分位数分 1-5 档（R 反向：越小分越高）。
**分层**：R、F、M 均 ≥4 → 重要价值客户；R 高但 F/M 高 → 流失预警；R 低 F 低 M 低 → 新客/沉睡。

```python
import pandas as pd

snap = df["下单日期"].max() + pd.Timedelta(days=1)
rfm = df.groupby("用户ID").agg(
    R=("下单日期", lambda s: (snap - s.max()).days),
    F=("订单号", "nunique"),
    M=("实付金额", "sum"),
)
rfm["R分"] = pd.qcut(rfm["R"], 5, labels=[5, 4, 3, 2, 1]).astype(int)  # R 越小越好
rfm["F分"] = pd.qcut(rfm["F"].rank(method="first"), 5, labels=[1, 2, 3, 4, 5]).astype(int)
rfm["M分"] = pd.qcut(rfm["M"].rank(method="first"), 5, labels=[1, 2, 3, 4, 5]).astype(int)
```

**要点**：qcut 在大量并列值时会报错，用 `rank(method="first")` 先打散（如上）；分层结果必须给出各层人数和金额占比。

## 2. 漏斗分析

**定义**：各环节转化率 = 下一环节人数 ÷ 上一环节人数。
**口径**：明确漏斗环节定义（如 曝光→点击→详情页→加购→下单→支付），环节顺序和时间窗（同一用户须在窗口内依次完成）。
**要点**：
- 转化率的**基数**要说清（按 UV 还是按会话）；
- 找出流失最大的环节（转化率最低的那一跳），下钻拆渠道/客群看是不是结构性问题。

## 3. 复购率 / 留存率

**口径（草稿）**：
- 复购率 = 统计窗口内下单 ≥2 次的用户数 ÷ 窗口内总下单用户数；
- 次月留存 = 首购月在 M 月、且 M+1 月仍有下单的用户数 ÷ M 月首购用户数（同期群 cohort 口径）。
**要点**：留存必须按**首购月同期群**算，不能拿全量用户糊一个数；复购窗口影响巨大（30 天 vs 90 天差异可达数倍），必须标注。

```python
df["首购月"] = df.groupby("用户ID")["下单日期"].transform("min").dt.to_period("M")
df["下单月"] = df["下单日期"].dt.to_period("M")
cohort = df.groupby(["首购月", "下单月"])["用户ID"].nunique().unstack()
retention = cohort.div(cohort.iloc[:, 0], axis=0)  # 第 0 列即首月基数
```

## 4. GMV 拆解

**口径**：GMV = 流量（UV）× 转化率 × 客单价；客单价 = GMV ÷ 订单数。
**用法**：GMV 异动时做因素拆解——分别计算三个因子的环比变化，定位异动主因
（例：GMV +5% = UV +12% × 转化率 −4% × 客单价 −3% → 主因是流量增长，但转化在恶化）。
**要点**：GMV 口径（含/不含取消和退款）必须与财务确认；拆解用乘法因子，注意交叉项。

## 通用提醒

- 大促/活动期间的数据尖峰单独标注，不与日常趋势混算环比。
- 所有"率"同时给出分子分母绝对值。
