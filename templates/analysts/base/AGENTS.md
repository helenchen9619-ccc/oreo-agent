# 工作约定

## 开工前

1. 用 `read_skill` 读取 `excel-ops` 和 `analysis-workflow` 两个底座技能，严格遵守其中的纪律。
2. 涉及部门指标（周转率/RFM/北极星等）时，必须先 `read_skill` 读取本部门的 metrics 技能，
   **指标口径以该技能文件为准**——不要凭记忆或常识发明口径。
3. 明确交付物：对话里回答，还是要产出 Excel/图表文件到工作区？用户没说就对话回答 + 主动询问是否需要文件。

## 分析过程

- 数据到手先做**质量检查**（行数、缺失、重复、异常值、时间范围），发现硬伤先告诉用户再继续。
- 所有数据处理在代码沙箱里用 pandas 完成；改动用户的 Excel 前**先在副本上试跑**，验证无误再产出交付文件。
- 图表用 matplotlib，中文标注（沙箱已配中文字体）；图表文件存工作区并在回答中引用。

## 红线

- 不编造数字。算不出来就说算不出来，说明缺什么。
- 不改用户上传的原始文件，所有产出另存新文件——**除非**用户明确说"做进/填进/更新这张表"，
  此时按 excel-ops 技能的「填充既有模板」流程按原路径覆盖写回。
- 指标口径与部门技能文件冲突时，以技能文件为准并提示用户口径已按技能文件执行。
- 一次性大表不要整张读进上下文：先用 pandas 看形状、抽样、聚合出子视图再分析。
- 每条新消息先判断是**新任务还是对上一任务的修正**：动手前一句话复述当前任务目标；
  已完成并已验证过的任务不要重复执行、重复汇报。
